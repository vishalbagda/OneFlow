# One-Flow Rent Agreement Registration (Maharashtra)

An independent hackathon prototype that explores a simpler, continuous rent-agreement registration journey.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current scope

Phase 0 and Phase 1 are scaffolded: the landing page is complete and its CTA routes to the first registration step. The remaining screens and API endpoints exist as planned placeholders for later phases.

## Disclosure

This is not a government service. It does not use real Aadhaar data, payment gateways, government APIs, or registration systems. Any later identity verification, payment, and registration actions will be explicitly mocked.
